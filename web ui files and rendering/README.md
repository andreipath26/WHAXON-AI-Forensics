# Archived web captures and UI references

This directory contains the supplied Obsidian Kinetic design reference and imported GitHub-page text captures collected during earlier repository research.

## Source-of-truth rules

- The supplied UI implementation files in this directory remain the design/source inputs for the UI integration work. Do not replace them with the scraped captures.
- `obsidian_kinetic/DESIGN.md` is the design reference; it is not evidence that every design detail has passed runtime acceptance.
- Files named `extracted_text_*.md` are raw page captures. Several were captured from the original `andreipath26/WHAXON` repository; others are snapshots of historical GitHub pages, commits or directory listings. They are not current product documentation and must not be used to infer current code behavior.
- `whaxon_road_map_whats_next_full_scope.md` is an older copied roadmap. The authoritative roadmap is the root `WHAXON ROAD MAP - WHATS NEXT - FULL SCOPE.md`.
- `whaxon_v1.0.0_deployment_release_notes.md` was an unissued draft and is now replaced by an explicit disclaimer. It is not evidence of a v1.0.0 release.

For current product behavior, use the active repository's source and tests on `main`, [README.md](../README.md), [docs/README.md](../docs/README.md), [the documentation reconciliation register](../docs/DOCUMENTATION_RECONCILIATION.md), and the root master roadmap. For UI acceptance, use [docs/NEW_UI_INTERACTION_AUDIT.md](../docs/NEW_UI_INTERACTION_AUDIT.md) and roadmap §38.
