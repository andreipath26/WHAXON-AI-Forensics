# Assets

The GUI splash helper accepts a logo path and falls back to a text-only splash when the file is absent. The TUI currently renders its ASCII logo; terminal image rendering is disabled because graphics-protocol handling caused freezes/traversal issues.

`backforge.png` is an optional visual asset/reference. Its presence is not required for either interface to start, and this directory's contents should not be presented as proof of a particular UI appearance or acceptance state.
